## 프로젝트 개요

- **개발 기간:** 2018.09 ~ 2020.08
- **출시:** 2019년 11월
- **장르:** 배틀로얄
- **소속:** 해긴
- **팀 구성:** 총 20명 · 클라이언트 3명
- **기술:** Unity Engine 2020.3, C#, NGUI
- **관리 및 배포:** SVN, Jenkins

초기 개발부터 글로벌 출시, 라이브 유지보수와 CS 대응까지 참여했습니다.

## 담당 기능

- NGUI 기반 기존 프레임워크를 활용한 아웃게임 UI 및 콘텐츠 개발
- 캐릭터·장비·드론·인벤토리·도감 콘텐츠 개발
- 장비 장착·강화·비교·상세 정보 및 프리셋 기능 개발
- 로비·프로필·옵션·우편함·랭킹·퀘스트 UI 개발 및 개선
- 시즌 퀘스트·배틀스타·배틀패스·도전과제 콘텐츠 개발
- 리그·랭킹·친선전·팀전·챌린지 모드 콘텐츠 개발
- 출석·복귀 보상·시즌 종료 보상 및 이벤트 콘텐츠 개발
- 게임 내 재화와 패키지 상품을 판매하는 상점 콘텐츠 개발
- TCP 기반 실시간 채팅 시스템과 팀전·친선전 채팅 기능 개발
- 광고 시청 완료 확인 및 보상 지급 흐름 구현
- 팝업·툴팁·알림·가이드와 보상 획득 연출 개발
- Jenkins 기반 Android·iOS 빌드 및 스토어 검수·배포

## 주요 성과

- Animation Event에서 사용하는 캐릭터별 이펙트와 사운드를 자동 수집하고 미리 로드하여 전투 중 동적 로드에 의한 순간적인 프레임 저하 완화
- 캐릭터 리소스 로딩 흐름을 개선해 전투 진입 시간 단축
- TCP 기반 채팅 시스템을 구축하여 메시지 송수신과 연결 상태 처리 구조 구현
- 광고 시청부터 완료 확인과 보상 지급까지 이어지는 보상형 광고 흐름 구현
- 프로젝트 초기 개발부터 글로벌 출시와 라이브 운영까지 참여하며 업데이트·스토어 검수·QA 이슈 대응
