## 프로젝트 개요

- **개발 기간:** 2024.04.06 ~ 2024.04.20 · 2주
- **개발 형태:** 기획 및 클라이언트 1인 개발
- **장르:** 좀비 FPS
- **기술:** Unity, C#
- **형상 관리:** Git, GitHub

이동, 조준, 사격과 좀비 전투를 구현한 FPS 개인 프로젝트입니다. 플레이어 입력부터 전투 결과가 전달되기까지의 과정을 하나의 흐름으로 구성했습니다.

## 주요 구현

- FPS 시점의 이동, 조준, 사격 및 재장전 시스템 구현
- 좀비 AI와 플레이어 간 전투 흐름 구성
- 무기 및 전투 요소를 확장할 수 있는 구조 설계

## 개발 포인트

- FPS 전투에 필요한 이동, 조준, 사격과 피격 피드백을 직접 구현
- 기능 단위로 코드를 분리하여 유지보수와 확장성을 고려한 프로젝트 구조 구성
- 기능 추가 시 기존 코드에 미치는 영향을 줄이도록 역할별 코드 분리
