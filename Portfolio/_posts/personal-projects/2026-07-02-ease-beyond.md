## 프로젝트 개요

- **개발 기간:** 2026.07.02 ~ 진행 중
- **개발 형태:** 기획 및 클라이언트 1인 개발
- **장르:** 우주 크루즈 시뮬레이션
- **기술:** Unity, C#, WebGL
- **관리 및 배포:** Git, Web Hosting

Ease Beyond는 태양계 천체를 자동으로 순회하는 WebGL 프로젝트입니다. 사용자 입력 없이 행성 사이를 이동하도록 자동 주행과 카메라 전환을 구현했습니다.

## 주요 구현

- 태양계 천체를 순회하는 자동 주행 경로 구성
- 행성 간 이동과 카메라 연출 구현
- 브라우저 환경을 고려한 WebGL 빌드 및 배포

## 개발 포인트

- 사용자 조작 없이 다음 천체로 이동하는 주행 방식 구현
- 천체 사이의 거리와 이동 시간을 기준으로 주행 속도 조정
- 이동 구간에 따라 카메라 시점을 전환하도록 구성
- Unity 프로젝트를 WebGL로 빌드하고 웹 서버에 배포

자동 이동과 카메라 전환을 연결하고 브라우저에서 바로 실행되는 형태로 배포했습니다.
