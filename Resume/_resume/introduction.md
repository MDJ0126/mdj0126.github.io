**8년 차** 게임 클라이언트 프로그래머 **문동준**입니다.

Unity 기반 3개 프로젝트에서 초기 개발부터 글로벌 출시와 라이브 서비스까지 참여했습니다.

- 오버독스 (2019년 11월 출시)
- 데미안 전기 (2023년 4월 출시)
- 라스트헌터K: 서울 (2026년 4월 출시)

소규모 클라이언트 팀에서 로그인부터 아웃게임, 인게임 진입까지 클라이언트 시스템을 개발했습니다. 캐릭터와 전투 기능, 서버 통신, 리소스 관리, 빌드 환경과 내부 제작 도구도 담당했습니다. 출시 후에는 신규 콘텐츠 업데이트와 유지보수, CS 이슈에 대응했습니다.

프로젝트 구조는 CBD(Component-Based Development)와 객체 지향 프로그래밍(OOP)을 기반으로 설계해 왔습니다. 공통 기능은 컴포넌트로 만들어 여러 콘텐츠에서 재사용하고, 기능을 수정할 때 다른 시스템에 미치는 범위를 줄이는 방향으로 코드를 구성했습니다.

기능을 구현한 뒤에는 실제 빌드에서 발생하는 문제를 재현하고, 로그와 호출 흐름을 따라 원인을 찾았습니다. 해결한 이슈는 발생 조건과 원인, 수정 내용과 확인 방법을 문서로 남겨 팀에 공유했습니다.
