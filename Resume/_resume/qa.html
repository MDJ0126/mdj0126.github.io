어떤 개발자이신가요?

Unity와 C#을 중심으로 소규모 팀에서 아웃게임과 인게임 기능을 설계하고 구현해 온 게임 클라이언트 개발자입니다. 모르는 문제는 관련 자료와 재현 결과를 확인해 해결합니다. 현재는 개인 프로젝트에서 Unreal Engine을 사용하고 있습니다.

업무에서 가장 중요하게 생각하는 것은 무엇인가요?

출시 이후에도 수정하기 쉬운 구조를 만드는 것을 중요하게 봅니다. 공통 기능은 여러 콘텐츠에서 재사용하고, 한 기능의 변경이 다른 시스템에 미치는 범위를 줄이도록 코드를 구성합니다. 구조를 결정한 이유와 사용 방법은 문서로 남기고 팀의 네이밍 규칙을 따릅니다.

실무를 할 때는 어떻게 진행하나요?

기획·아트·서버 담당자와 요구사항과 작업 범위를 확인한 뒤 개발을 시작합니다. 기술 선택이 필요한 경우 작은 예제 코드로 먼저 검증하고, 결과를 공유해 적용 여부를 결정합니다.

협업할 때 어떤 강점이 있나요?

기획·아트·서버 담당자와 구현 조건을 확인하고, 기술적인 쟁점은 예제 코드와 문서로 정리해 공유합니다. 담당자가 정해지지 않은 문제도 재현 조건을 확인한 뒤 관련 직군과 해결 방법을 논의합니다.

새로운 기술은 어떻게 도입하시나요?

먼저 빈 프로젝트에서 필요한 기능을 작게 구현해 호환성과 제약 사항을 확인합니다. 테스트 결과를 동료들과 공유해 도입 여부를 결정하고, 적용 범위를 나눠 프로젝트에 반영합니다.

AI 도구를 어떻게 활용하시나요?

AI 도구를 설계 검토, 기술 조사, 반복 작업 자동화와 문제 분석에 사용합니다. 생성된 결과는 프로젝트 구조와 요구사항에 맞는지 소스 코드와 실행 결과를 통해 다시 확인합니다.
